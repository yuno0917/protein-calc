# 1日のタンパク質計算機

体重と目的から、1日にとりたいタンパク質の量、1食あたりの量、プロテイン何杯分かを計算する Web ツールです。公開先は https://yuno-lab.com/protein-calc/ です。

- 筋肉をつけたい：体重1kgあたり1.6〜2.2g（Morton 2018）
- 減量中：体脂肪率があれば除脂肪体重1kgあたり2.3〜3.1g（Helms 2014）、なければ1.6〜2.2g/kg
- 健康のため：体重1kgあたり約0.9g（食事摂取基準2025の推奨量の考え方）、65歳以上は1.2g/kg以上
- 足りない分は、日本人の平均摂取量（令和6年国民健康・栄養調査、20歳以上71.5g）との差。差が5g未満なら足りているとみなし、プロテイン1杯20gで杯数に直す
- 食べ物の表は、日本食品標準成分表（八訂）増補2023年の値 × 目安の量
- コスパ計算：値段・内容量と、メーカー公式の1食の量・タンパク質（`DATA.products`、2026年10月7日に確認）から、タンパク質20gあたりの値段と、足りない分を足したときの1か月の値段を出す。値段は自動では取らず、入れてもらう。商品ごとに楽天市場の検索結果か、マイプロテイン公式サイトへの紹介リンクを出す

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・結果・食べ物の表・考え方・よくある質問・参考文献・免責 |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `js/pc-calc.js` | 研究と基準の数字、計算、入力のチェック |
| `js/app.js` | フォーム・描画・保存・共有リンク |
| `css/style.css` | ほかのツールと共通（bench-program のものをコピー） |

数字を変えたら `tests.html` を開き、テストがすべて通ることを確認してください。`index.html` の食べ物の表と「考え方」の数字も合わせて直します。
